# Unknown-Identity-Alert
A basic project that verifies face encodings to authorize a person


🔍 Features
🎥 Live Webcam Feed: Continuously monitors faces using your device’s webcam.

🧠 Face Recognition: Compares detected faces with a database of known faces using face encodings.

✅ Access Control: If the face is recognized, a success message is logged.

🚨 Alert System: If the face is unrecognized, a Pushbullet notification is sent to your smartphone in real time.
